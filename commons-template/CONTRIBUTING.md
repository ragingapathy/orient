# Contributing

The easiest way is from [Orient](https://github.com/ragingapathy/orient): open a place, expand **People & notes**, choose **Share this note**, and follow the steps. It opens GitHub with your contribution filled in.

You can also add a file by hand under `contributions/` (see `commons/README.md` in the Orient repository for the format). Each pull request should add new files only.

Please write about places, not people. Do not include names, contact details or anything that could identify someone. You share your words under CC BY 4.0.
